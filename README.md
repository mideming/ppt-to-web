# 崇明岛乡村住宅 - 前端展示网站

基于《崇明岛乡村住宅》PPT研究报告创建的交互式前端展示网站。

## 项目简介

本项目将PPT中的核心内容转化为现代化的网页展示，包含诉求、设计、施工三大板块，以及轮播图、响应式设计和丰富的交互功能。

## 功能特点

### 🎯 核心功能
- **响应式导航栏**: 固定定位，移动端汉堡菜单
- **自动轮播图**: 5秒自动切换，支持手动控制和键盘操作
- **三大内容板块**: 诉求、设计、施工的详细展示
- **图片画廊功能**: 从PPT提取的图片展示，支持分类筛选和大图预览
- **交互体验**: 平滑滚动、悬停效果、点击交互
- **完全响应式**: 适配各种屏幕尺寸

### 📱 技术实现
- 纯原生JavaScript，无框架依赖
- 现代CSS布局（Flexbox/Grid）
- 面向对象编程设计
- 模块化代码结构
- 图片懒加载（IntersectionObserver）
- 响应式图片网格（CSS Grid）
- 大图预览模态框

## 项目结构

```
├── index.html              # 主页面
├── css/
│   └── style.css          # 所有样式
├── js/
│   ├── data.js            # 从PPT提取的结构化数据
│   └── main.js            # 主要交互逻辑
├── analyze_ppt.py         # PPT分析脚本（支持图片提取）
├── images/                 # 从PPT提取的图片资源
│   ├── demands/           # 诉求相关图片
│   ├── design/            # 设计相关图片
│   ├── construction/      # 施工相关图片
│   └── images_data.json   # 图片元数据
└── 崇明岛乡村住宅.pptx    # 原始PPT文件
```

## 快速开始

1. **直接运行**: 在浏览器中打开 `index.html` 即可
2. **无需安装**: 所有资源本地化，无需网络连接
3. **无需后端**: 纯前端项目，无服务器要求

## 内容来源

所有展示内容均来自《崇明岛乡村住宅》PPT研究报告，通过Python脚本分析提取并结构化存储。

### 三大板块内容

#### 1. 诉求
- 项目背景与政策支持
- 年龄结构需求分析（老年、中青年、青少年）
- 生态与生活习惯适配

#### 2. 设计
- 功能布局设计（一层、二层、三层）
- 平面设计标准模块
- 立面风格设计（欧式、新中式、现代、田园）

#### 3. 施工
- 一站式服务流程
- 施工环节详解
- 质量保障体系

### 图片画廊功能
- **图片提取**: 从PPT自动提取图片并生成缩略图
- **分类筛选**: 按诉求、设计、施工分类浏览
- **大图预览**: 点击缩略图查看高清大图
- **键盘导航**: 使用左右箭头切换图片，ESC键关闭
- **懒加载**: 滚动时自动加载图片，优化性能
- **响应式网格**: 自适应不同屏幕尺寸

## 开发说明

### 数据管理
- 所有内容数据存储在 `js/data.js`
- 使用 `analyze_ppt.py` 可从PPT提取数据
- 数据结构清晰，易于维护和扩展

### 代码架构
- **Carousel类**: 轮播图功能
- **ContentRenderer类**: 动态内容渲染
- **Navigation类**: 导航和滚动控制

### 样式设计
- 每个板块有独特的主题色
- 卡片式布局，现代简约风格
- 丰富的动画和过渡效果
